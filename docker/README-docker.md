## Docker

### Development (LiveReload)

```bash
docker compose up
# → http://localhost:4000
```

Sources are mounted as a volume: every change is picked up live, no container rebuild needed.

### Production (nginx)

```bash
docker compose -f docker-compose.prod.yml up -d --build
# → http://localhost
```

Builds the static site with `JEKYLL_ENV=production`, then serves it with nginx (security headers, gzip).

The Content-Security-Policy is generated by the theme (`_includes/csp.html`) from your `_config.yml`: services you configure there (analytics, comments) are allowed automatically, other hosts go in `theme_config.security.csp_extra`. `docker/security-headers.conf` only adds the headers a `<meta>` tag cannot carry (`frame-ancestors`, HSTS…).
