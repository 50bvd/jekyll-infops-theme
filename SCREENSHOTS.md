# Screenshots to take

Interface screenshots referenced by the articles. Until a file exists it is **not shown in production**;
on the **preprod** each missing one appears as a dashed box with its path (`show_screenshot_placeholders: true`).

Tips: PNG (JPG for photos), ~1600 px wide, crop to the relevant part, blur hostnames/IPs/tokens you do not want public.
Drop the file at the exact path, commit, then `./scripts/deploy.sh all`.
